A tiny moderation stack

Small surface.
Thoughtful underneath.

Jevfanity turns one sentence into a set of focused moderation questions. That keeps the result legible: you get one overall signal, plus the category scores that explain it.

The API runs on Cloudflare Workers. The browser demo and the npm client both talk to the same small HTTP contract.

01

Ask clearly

Jev receives one focused question for profanity, slurs, harassment, threats, and sexual content.

02

Read context

Long text is chunked, lookalike Unicode is normalized, and each category keeps its strongest signal.

03

Return detail

Applications get a simple flagged value, confidence scores, selected policy level, and usage metadata.
